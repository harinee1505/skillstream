# SkillStream

Interactive video-based learning and assessment platform.

## Included
- Clean student learning dashboard and course catalog
- Sequential video → question → coding problem flow
- Video progress/resume tracking in browser
- MCQ understanding checks and problem unlocks
- Coding practice UI with server endpoint
- Analytics, strengths/weaknesses and recommendations UI
- Supabase production database schema with RLS
- Vercel-ready deployment configuration

## Database
Open Supabase SQL Editor and run `supabase_schema.sql`. Then create a Supabase project and save its Project URL + anon key in SkillStream → Settings.

## Deploy
This project is Vercel-ready. Build command: `npm run build`. Output directory: `dist`.
