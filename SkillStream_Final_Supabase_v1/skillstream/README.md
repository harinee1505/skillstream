# SkillStream

Production-oriented interactive learning platform connected to Supabase.

## Features
- Supabase email/password authentication and logout
- Multi-user profiles and role-aware instructor navigation
- Courses loaded from the database
- Per-student enrollments and learning progress
- Video lesson playback with progress persistence
- Mock assessment with database-stored attempts and scores
- Practice lab UI
- Analytics, certificates and premium responsive UI

## Run locally
`npm start`

Open http://localhost:3000

## Deployment
Deploy the `skillstream` folder to Vercel as a static site. The Supabase URL and publishable key are configured in `index.html`.
